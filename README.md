# ئەپی مزگەوتەکانی پێنجوێن (Penjwen Mosques App)

سیستەمێکی سەردەمیانە و تایبەت بە تۆمارکردن و بەڕێوەبردنی مزگەوتەکانی پێنجوێن بە دیزاینێکی سەوزی کاڵ، کاتەکانی بانگ (بە توانای دەستکاریکردن)، وتاری هەینی (بە تۆمارکردنی دەنگ بە MP3)، و چوارگۆشەی شین.

---

## تایبەتمەندییە سەرەکییەکان:

### ١. لابردنی دووگمەی سێرج و فلتەرەکان:
- تەواوی باڕی گەڕان (سێرج) و فلتەرەکان (وتاربێژ، پێشنوێژ، بانگبێژ، خاوەن وتار، باکئەپ) بە تەواوی لابران بۆ ئەوەی ڕووکاری ئەپەکە سادە، پاک و خێرا بێت.

### ٢. دەستکاریکردنی کاتەکانی بانگ:
- لە بەشی شریتی بانگەکاندا دووگمەی **«دەستکاری کاتەکان»** دانراوە.
- ئەگەر کاتی هەر بانگێک دروست نەبوو، دەتوانیت بە دڵی خۆت کاتەکانی هەر شەش کاتەکە (بەیانی، خۆرهەڵات، نیوەڕۆ، عەسر، مەغریب، عیشا) دەستکاری بکەیت و پاشەکەوتی بکەیت.
- ژماردنی کاتی ماوە بۆ بانگی داهاتوو ڕاستەوخۆ بەپێی کاتە دەستکاریکراوەکان کار دەکات، هەروەها دووگمەی «گەڕانەوە بۆ کاتی خودکار»یشی تێدایە.

### ٣. خەزنکردنی دەنگی وتار بە MP3:
- لەو خانەیەی کە ناونیشانی وتاری تیا دەنووسرێت (لە فۆڕمی تۆمارکردن و دەستکاری)، دووگمەی **«خەزنکردنی دەنگ بە MP3»** دانراوە.
- هەروەها لەسەر کارتی مزگەوتەکەش دووگمەی خێرای بارکردنی MP3 هەیە.
- کاتێک فایلی دەنگی وتارەکە دادەنێیت، پلەیەرێکی دەنگیی مۆدێرن دەردەکەوێت بۆ ئەوەی ڕاستەوخۆ بتوانرێت گوێ لە وتارەکە بگیرێت.

### ٤. ژمارەی تەلەفۆنەکان بە ئینگلیزی:
- سەرجەم ژمارەی تەلەفۆنەکانی مامۆستایان، وتاربێژ، پێشنوێژ و بانگبێژ بە ژمارەی ئینگلیزی (0-9) و ئاراستەی چەپ بۆ ڕاست (LTR) دیزاین کراون.

### ٥. کارکردن بە ئۆفلاین (بێ ئینتەرنێت) و ئۆنلاین (PWA):
- ئەپەکە بە تەواوی وەک Progressive Web App (PWA) دیزاین کراوە بە پشتبەستن بە Service Worker و LocalStorage/IndexedDB.
- ئەگەر ئینتەرنێت نەبێت یان بپچڕێت، هەموو بەشەکانی ئەپەکە (تۆماری مزگەوتەکان، کاتەکانی بانگ، گەڕان، دەنگی وتارەکان بە MP3) بەبێ کێشە کار دەکەن.
- نیشاندەری دۆخی هێڵ (سەرهێڵ 🟢 / ئۆفلاین 🟠) لە سەرەوە هەیە.

### ٦. ناردن بۆ مامۆستا بەڕێزەکانی پێنجوێن:
- دووگمەی تایبەت بە **«ناردن بۆ مامۆستایان»** لە بەشی سەرەکی ئەپەکەدا هەیە.
- بە یەک کلیک پەیام و بەستەری ئەپ لە ڕێگەی واتسئاپ (WhatsApp) یان تێلێگرام (Telegram) دەنێردرێت بۆ مامۆستایان.
- فایلی **`Penjwen_Mosques_App.zip`** لەسەر دیسکتۆپ ئامادەیە بۆ ناردنی ڕاستەوخۆ بە دۆکیومێنت کە بەبێ ئینتەرنێت ١٠٠٪ کاردەکات.
- ڕێنمایی خستنەسەر شاشەی مۆبایل (Add to Home Screen) بۆ ئایفۆن و ئەندرۆید لە ناو ئەپەکەدا ڕوونکراوەتەوە.
