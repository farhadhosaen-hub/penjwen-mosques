داگرتن و خستنەسەر شاشە وەک ئەپ

بۆ مۆبایل (ئایفۆن و ئەندرۆید) و کۆمپیوتەر

بۆ مۆبایلی ئایفۆن (iPhone - Safari):
  1. لە وێبگەڕی سەفاری (Safari) لە خوارەوەی شاشە کلیک لە دوگمەی هاوبەشکردن (Share ) بکە.
  2. بڕۆ خوارەوە و هەڵبژاردنی «Add to Home Screen / خستنەسەر شاشە» دابگرە.
  3. لە سەرەوە کلیک لە Add بکە؛ دەستبەجێ بە لۆگۆی فەرمی دەچێتە سەر شاشەی مۆبایلەکەت.
بۆ مۆبایلی ئەندرۆید (هەموو ئەندرۆیدەکان ٥ بۆسەرەوە):
Android 5.0+
  1. کلیک لە دوگمەی سەرەکی «داگرتنی ئەپ» بکە.
  2. یان لە وێبگەڕ/کرۆم کلیک لە سێ خاڵەکەی سەرەوە (⋮) بکە.
  3. هەڵبژاردنی «Install app / ئەپەکە دابەزێنە» یان «Add to Home screen / خستنەسەر شاشە» بکە.
داگرتنی فایلی تەواوی ئەپ (بەبێ ئینتەرنێت): فایلی ئەپ دابەزێنە
بۆ کۆمپیوتەر (Windows / Mac):
  1. لە کرۆم یان ئێج، لە بەشی سەرەوە لە لای ڕاستی ناونیشانەکە کلیک لە نیشانەی ئەپ (Install ⊕) بکە.
  2. پاشان کلیک لە Install بکە. ئەپەکە دەچێتە سەر دیسکتۆپت و لە پەنجەرەیەکی سەربەخۆ دەکرێتەوە.

داگرتن و خستنەسەر شاشە وەک ئەپی فەرمی بە یەک کلیک

مامۆستای بەڕێز، دەتوانیت ئەم ئەپە بە یەک کلیک بخەیتە سەر شاشەی مۆبایل یان کۆمپیوتەرەکەت، تاوەکو لەمەودوا بە شێوەیەکی سەربەخۆ، خێرا و بە تەواوی بێ ئینتەرنێت کاربکات.

خستنەسەر شاشە لە ئایفۆن (iPhone - Safari):
  1. لە خوارەوەی وێبگەڕی سەفاری، کرتە لە دوگمەی هاوبەشکردن (Share ) بکە.
  2. هەڵبژاردنی (Add to Home Screen / خستنەسەر شاشە ⊞) بکە.
  3. لە سەرەوە کرتە لە Add بکە، ئەپەکە دەچێتە سەر شاشەت.
ئەپێکی پارێزراوە و هیچ ڕیکلام و تێچوویەکی نییە

دابەزاندنی فایلەکان بۆ ناو ئامێرەکەت بۆ کارکردنی بەردەوام بە ئینتەرنێت و بێ ئینتەرنێت

فایلی فەرمی APK ڕاستەوخۆ دادەبەزێتە ناو مۆبایلەکەت و بێ ئینتەرنێت کاردەکات

داگرتنی فایلی APK بۆ ناو مۆبایل

٢. داگرتنی ئەپ بۆ مۆبایلی ئایفۆن (iPhone & iPad)

داگرتنی فایلی تەواوی ئەپ بۆ ناو ئایفۆن یاخود دانانی لەسەر شاشە بەبێ ئینتەرنێت

ئایفۆن و ئایپاد

دەتوانیت فایلی ئەپەکە دابەزێنیتە ناو بەرنامەی Files ی ئایفۆن، یان لە Safari بە یەک چرکە بیخەیتە سەر شاشەی سەرەکی وەک ئەپ:

داگرتنی فایلی تەواوی ئەپ بۆ ناو ئایفۆن
ڕێگای فەرمی ئایفۆن بۆ دانان لەسەر شاشە (Add to Home Screen):
  1. لە وێبگەڕی Safari لە خوارەوە کرتە لە دوگمەی هاوبەشکردن (Share ) بکە.
  2. بڕۆ خوارەوە و هەڵبژاردنی «Add to Home Screen / خستنەسەر شاشە ⊞» هەڵبژێرە.
  3. لە سەرەوە لای ڕاست کرتە لە دوگمەی Add بکە؛ ئەپەکە بە لۆگۆی فەرمی دەچێتە سەر شاشە و بەبێ ئینتەرنێت هەمیشە کاردەکات.

٣. داگرتنی ئەپ بۆ کۆمپیوتەری ویندۆز (Windows 7, 8, 10, 11)

فایلی سەربەخۆی ئۆفلاین بە تەواوی کۆد و داتاکانەوە بە شێوەی داونلۆد دادەبەزێت

ئۆفلاین ١٠٠٪ (2.5 MB)

فایلەکە دادەبەزێتە ناو فۆڵدەری Downloadsی کۆمپیوتەرەکەت. تەنها دوو کلیکی لەسەر بکە؛ دەستبەجێ بەبێ ئینتەرنێت دەکرێتەوە و کاردەکات:

داگرتنی فایلی ئەپی ویندۆز (HTML Standalone) پاکێجی زیپی ویندۆز (ZIP)

٤. داگرتنی هەموو فایلەکانی ئەپەکە پێکەوە (Full Master ZIP)

سەرجەم فایلی ئەپەکانی ویندۆز، ئەندرۆید، ڕەنکەر و دۆکیومێنت بە یەک پاکێج
